## 📌 Тема работы

Прогноз цены жилья на датасете **California Housing Prices**.

Цель работы — изучение основ линейной регрессии, построение моделей
(Linear, Lasso, Ridge), оценка их качества и сравнение результатов
до и после понижения размерности методом главных компонент (PCA).

---

## 📊 Используемый датасет

**California Housing Prices** — встроенный датасет из `sklearn.datasets`.

- Целевая переменная: `MedHouseVal` (медианная стоимость дома)
- Количество признаков: 8 (числовые)
- Количество объектов: ~20 640

Датасет загружается автоматически при запуске ноутбука,
дополнительные файлы не требуются.

---

## 🛠️ Что сделано в работе

1. **Загрузка датасета** через `fetch_california_housing`.
2. **Первичный анализ (EDA):**
   - структура и статистики,
   - проверка пропусков,
   - гистограммы распределений признаков и целевой переменной.
3. **Предобработка данных:** удаление пропусков, кодирование
   категориальных признаков (если есть).
4. **Анализ мультиколлинеарности:**
   - матрица корреляций,
   - расчёт VIF-коэффициентов.
5. **Построение моделей на исходных данных:**
   - Linear Regression,
   - Lasso (L1-регуляризация),
   - Ridge (L2-регуляризация),
   - кросс-валидация (5 фолдов),
   - метрики: RMSE, R², MAPE.
6. **Понижение размерности (PCA):**
   - стандартизация данных,
   - сохранение 95% объяснённой дисперсии.
7. **Построение моделей на главных компонентах** и сравнение
   с результатами на исходных признаках.
8. **Формулировка выводов** по итогам сравнения.

## 💡 Основные выводы

1. **EDA** показал разные масштабы признаков и скошенность
   целевой переменной — потребовалась стандартизация.
2. **VIF-анализ** выявил мультиколлинеарность (VIF > 10) у ряда
   признаков: `AveRooms`, `AveBedrms`, `Households`, `Population`.
3. **На исходных данных** лучший результат показала модель **Ridge**:
   L2-регуляризация компенсирует мультиколлинеарность.
4. **PCA** сократил число признаков, сохранив 95% дисперсии.
   Качество моделей на компонентах оказалось сопоставимым
   с исходными данными, но интерпретируемость снизилась.
5. **Пути улучшения:** подбор `alpha` через `GridSearchCV`,
   добавление полиномиальных признаков, использование
   нелинейных моделей (Random Forest, Gradient Boosting).
